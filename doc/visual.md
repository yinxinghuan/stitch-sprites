# 《拆线精灵》视觉圣经

## 1. Visual thesis

- **游戏与受众**：面向微信竖屏用户的轻量排序解谜；不要求玩家了解专业刺绣知识。
- **情绪承诺**：先享受一群小精灵忙碌协作的生命力，再获得厚实绣面逐层消退、隐藏底图显现的拆解满足感。
- **一句话视觉命题**：在明亮的微缩手作桌面上，纽扣大小的拆线精灵从外向内挑开真实可触的十字针脚，并把彩线绕回线轴。
- **标志性瞬间**：最后一个“×”被挑开，彩线嗖地收回线轴，整块绣面落下并揭开藏在下面的小图，精灵们沿绣绷边缘庆祝。
- **必须具备**：材质可触、颜色清楚、角色有生命。
- **避免方向**：传统中国风符号堆叠、纯二维默认像素游戏、糖果式高光塑料 UI。

## 2. Composition and camera

- **方向与比例**：手机竖屏，主验收 390×844，窄屏 320×568；响应式 DOM 外壳包裹固定逻辑网格。
- **镜头与透视**：轻微俯视的正交微距视角；绣布保持网格可读，不使用强透视造成格子变形。
- **焦点**：屏幕中上部的圆角绣绷和图案，占可用高度约 48–55%。
- **前中后景**：前景为少量越过绣绷边缘的线头；中景为线团、针脚和精灵；背景为失焦的浅色手作桌面。
- **HUD 安全区**：顶部仅保留关卡名、剩余线团和声音控制；底部安全区上方放线轴堆，关键线轴不贴近 Home Indicator。
- **注意路径**：标题/目标一句话 → 发光的外层线团 → 可选线轴 → 五个针位。

## 3. Color

- **桌面背景**：`#E8E0D3` 亚麻灰；暗部 `#B9AA96`。
- **绣布表面**：`#FFF9EC`；网孔 `#D8CDBB`；未拆针脚阴影 `#8B7968`；底图使用低饱和墨彩，不与线色争夺路径判断。
- **主文字**：`#2A2930`；次文字 `#68626A`。
- **行动强调**：天空蓝 `#4E8BCB`；完成奖励 `#F0B84A`；危险 `#C94F56`；成功 `#4B9B6B`。
- **线色**：珊瑚红 `#E85B67`、向日黄 `#F2C14E`、叶绿 `#5FAE73`、湖蓝 `#4E9CCC`、薰衣草紫 `#8E75C5`、深墨 `#3B3A47`。
- **使用比例**：65% 中性桌面与绣布、25%图案线色、10%状态强调。
- **禁止**：大面积红金、霓虹渐变、状态只靠红绿、未进入线色表的随机高饱和色。

## 4. Typography

- **展示文字**：`"PingFang SC", "Noto Sans CJK SC", system-ui, sans-serif`，700。
- **正文/UI**：同一字体族，500–600；不使用仿手写字体承载规则。
- **数字/HUD**：系统圆体优先，700，使用等宽数字特性。
- **尺度**：标题 24–28px；状态 16px；线轴数字 18–22px；辅助标签最低 13px，仅用于非交互短标签。
- **规则**：不使用全描边大字；危险和完成可使用 1px 深色投影，不以描边代替对比度。

## 5. Shape, material, and lighting

- **形状语言**：绣绷是圆角矩形，线轴为扁平绕线板，精灵主体为不对称软团；功能控件保持简洁圆角矩形或圆形。
- **边框与阴影**：绣布使用内嵌压痕；线团使用短而柔的接触阴影；UI 阴影不超过两层。
- **材质目标**：最终版绣布有规则网孔，待拆针脚使用可辨认的线材；拆开后留下清楚的空白网孔。当前机制灰盒把原图每格细分为 2×2 个完整小针脚，单颗占自身格约 96%，最终针脚材质下一阶段再定。
- **光线**：左上方柔和窗光，右下接触阴影；完成时增加一次沿丝线移动的窄高光。

## 6. Characters, environments, and assets

- **比例与轮廓**：精灵约为单个格子的 0.8–1.1 倍；圆形身体、两只短脚、两根像线头的触角和一个明显的针形工具。不同颜色保持相同物种轮廓，表情和小配件提供个体差异。
- **表情动作**：期待、忙碌、用力拉线、找不到工作的困惑、针位拥挤时的紧张、完成后的跳跃。
- **透视与细节**：角色与绣布共享轻俯视角；在 320px 宽屏仍能看清眼睛、触角和手中针，不添加只能在大图看见的复杂服装。
- **实现方式**：首个切片用 Canvas 矢量绘制和程序化纤维纹理，避免混入摄影贴图或风格不一的生成素材。

## 7. UI and icons

- **图标**：自绘统一 SVG，2px 圆角描边；只使用声音、重开和继续三个必要图标。
- **按钮**：触控目标至少 44×44px；主按钮为深墨底浅字，次按钮为绣布底深字。
- **HUD**：剩余线团使用“线团 24”文字和小型线团图形，不使用可能被误解为教学进度的 `3/5`。
- **针位**：明确画成针垫上的五个独立孔；空位、等待、正在工作、危险和完成均有形状或动效差异，不只变色。
- **状态**：按下下沉 2px；禁用降低对比并显示锁线轮廓；等待时角色坐下；危险时线条收紧；成功时针位释放。
- **Emoji**：不得作为功能图标。

## 8. Motion and VFX

- **性格**：精灵动作弹性轻快，绣线动作有阻力和回弹；日常 UI 不漂浮。
- **时长令牌**：按压 90ms、线轴入位 180ms、精灵出发 70ms、单个细针脚处理循环约 52ms、等待坐下 220ms、底图揭晓 700ms。
- **拆线峰值**：拆线针挑起为预备，交叉点松开为接触，整根彩线抽离并飞回线轴为峰值，空白绣布轻弹为收束。
- **粒子**：仅使用 1–3 根短纤维和细小线屑，寿命 250–450ms；禁止彩纸爆炸和全屏星星。
- **屏幕震动**：普通动作无；缠线失败最多 2px、120ms。
- **减少动态**：移除角色弹跳、路径弧线和镜头拉远，保留针脚即时状态、危险颜色和完成构图。

## 9. References translated into principles

- **蚂蚁搬运像素类游戏**：借用“很多小单位可视化自动处理”和“有限等待槽”的节奏；不复制蚂蚁、洞口、关卡图案、UI 布局和素材。
- **家用十字绣**：借用网格绣布、成对斜针、线板和绣绷的可理解材质；游戏行为是幻想式拆线，不宣称模拟真实拆绣工艺。
- **微缩工作场景动画**：借用角色与日常物体的尺度反差，让系统状态通过角色行为表达；不把角色做成不影响规则的背景装饰。

## 10. Anti-patterns

- 禁止祥云、宫灯、卷轴、仿古印章、红金宫廷配色等“中国市场＝中国风”的套用。
- 禁止把针脚缩在大逻辑格中央制造宽缝；需要更小颗粒时提高真实网格密度，并让完整颗粒贴满自身格。
- 禁止玻璃拟态卡片、霓虹发光、糖果塑料按钮和通用手游金色边框。
- 禁止在首次进入时显示多页教学、技术术语或完整规则清单。
- 禁止精灵遮挡外层可达线团、线轴数字或针位状态。
- 禁止把路径可达性只用颜色高亮表达；需要轮廓、空间接触和角色路径共同说明。

## 11. Vertical-slice acceptance

- **入口**：进入后立即看见绣布、精灵和第一卷发光线轴，首个输入在 3 秒内可发生。
- **游戏中**：不读文字也能看出哪些线团在外层、线轴还剩多少针、哪个针位正在工作或等待。
- **高反馈**：至少一次连续拆除 6 格，表现出精灵移动、交叉针脚抽离、线轴计数和空路真实打开。
- **完成**：绣面清空后完整底图留在屏幕上供欣赏，精灵庆祝但不遮挡主体。
- **窄屏**：320×568 下绣布、五针位和至少一层线轴同时可见，触控目标不小于 44px，无横向溢出。
- **针脚密度**：正常关 28×28 在 320px 宽度下仍须辨认完整的“×”与外层边界；整颗粒约占自身格 96%，相邻颗粒近乎贴合，不得呈现按钮阵列式宽缝。
- **视觉 QA**：需保留 390×844 与 320×568 的 platform-layout 首轮和复验截图，以及一个 external-guest 检查；任何 P0/P1 必须修复后再验。
