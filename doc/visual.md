# 《拆线精灵》视觉规范

## 1. Visual thesis

- **受众**：微信竖屏用户，不要求了解刺绣术语。
- **情绪承诺**：先看黑色小精灵排队忙碌，再享受一幅厚实十字绣逐层被拆空的满足。
- **一句话方向**：明亮的现代手作桌面上，小精灵在圆形木绣绷中拆解色彩饱满的具象十字绣。
- **必须具备**：原图保真、圆绷完整、角色有生命、选择因果清楚。
- **避免**：传统中国风符号堆叠、抽象技术术语、像素色块重绘、糖果塑料 UI。

## 2. Composition and camera

- 主验收尺寸 390×844，窄屏 320×568；平台内构图不为外部访客栏预留固定顶部空间。
- 自上而下为：关卡 HUD、单句因果提示、圆形绣绷、五个轴位、四列可选线轴。
- 绣绷始终是第一视觉焦点，完整圆形，不允许圆角方框或长方形裁图框。
- 每幅图先最小化自身边距，再在 1:1 透明画布中居中；主体与内圈留出稳定呼吸边，不得触碰或越过木框。
- 逻辑网格只决定清除区域；源纹理一次性铺入同一几何，不对图案进行非等比拉伸。

## 3. Pattern asset contract

### 源图切分

1. 按针脚前景密度的低谷寻找素材页分割，不假设每格等宽，也不依赖不稳定的白线。
2. 找到闭合主图形；删除边界外的小组件、布纹噪声和相邻图案碎片。
3. 主体不得有“飞地”，但图案内部的设计留白保留。
4. 裁切后四边均有正余量，并输出独立 1:1 审核图；长条联系表不作为裁切证据。

### 点对点与密度

- 不强制所有素材拥有相同针眼数。候选 B/C/D 使用 7px 原生针距，旅程图使用 5px，AlterU 章使用 8px。
- 逻辑色图从原生针点取样，不缩放到统一尺寸；玩法颜色最多六种。
- 可见棋盘使用 `public/patterns/<key>.png` 中的源十字绣纹理。禁止用统一 `X`、纯色块或低分辨率母版替换。
- 清除时按逻辑针点建立遮罩，只擦掉对应源纹理块；高清纹理与判定颜色是两层数据。

### 调色

- 每关从自己的源图提取红、黄、绿、蓝、紫、墨代表色；线轴、轴位和动态线束跟随该关调色板。
- 背景布色、针孔和纤维样式追随源图的暖白手作质感，避免统一灰蒙滤镜。
- 颜色顺序信息同时通过线轴符号和明暗表达，不只依赖色相。

## 4. Color and material

- 桌面：亚麻米灰 `#E8E0D3`，配低对比粉绿光斑。
- 绣布：暖白 `#FFF9EC` 到 `#E9DCC5` 径向变化；针孔与经纬线可见但弱于图案。
- 木绷：蜂蜜木色，左上柔光、右下接触阴影，内外环层次清楚。
- 文字：主色 `#2A2930`，次色 `#68626A`。
- 轴位：暖棕皮革/木质感；空位使用虚线缺口，不显示“3/5”式说明数字。
- 线轴比例固定约 19:20，四列等宽等高、中心与间距一致；后牌层数不得改变首牌尺寸。

## 5. Characters

- 精灵以黑色为主体，在密集关卡中也保持至少 8.6px 绘制半径，并比上一版放大约 15%；圆身、短脚、线头触角和两只清楚的眼睛。
- 队伍颜色只进入眼部/胸前符号、触角端点、工具与线束，不把整个角色涂成彩色。
- 精灵脚下有淡椭圆接触影；步行时影子保持贴布，起飞时缩小变淡。
- 去程必须地面行走，不能瞬移或直接飞向目标；离洞后才逐渐散队。
- 回程允许离地：先走弧线，再在靠近洞口时转为直线下落。

## 6. UI and typography

- 字体：`PingFang SC`, `Noto Sans CJK SC`, system-ui；标题 18–24px，状态 14–16px，线轴数字 18–22px。
- 功能图标为同一套 2px 圆角描边 SVG；Emoji 不作为功能图标。
- 重开图标使用同心圆弧与在圆弧端点闭合的箭头，不使用箭头尖与圆弧分离的旧手写路径。
- 顶部左侧只显示两位关卡编号与图鉴图标，不常驻游戏名和作品标题；完整作品名留在图鉴与结算页。
- 排行榜入口与剩余针脚、重开、声音处于同一排：无记录时只显示金杯；有记录后显示金杯、榜首头像与紧凑分数，头像不可用才回退为中文前两字或英文前三个字母；完整分数留在榜单内，也不悬浮覆盖绣绷。
- 重开、声音、关闭和主按钮均至少 44×44px；移动端不依赖 hover。
- 极窄屏仍必须完整保留关卡编号、图鉴入口、剩余针脚、排行榜、重开和声音；榜首分数允许使用 `1.3万 / 12.7K` 一类紧凑写法。
- 排行榜属于可选社交层：宿主支持时显示同体系奖杯入口与暖白绣布材质榜单；宿主不支持时整层不渲染、不占位。
- 绣品册为两列滚动卡片，按 2/3/4/5/6 种线色分章；已解锁缩略图直接使用源纹理，未解锁卡片只显示关卡编号与统一锁形，不提前泄露作品名、图案或颜色缩略图。
- 绣品册与完成结算共用圆形绣绷缩略图合同：方形源纹理必须裁入圆框，四角不得露出暖白方底，也不得越过外圈。
- 结算页使用十字绣缩略图作装饰，不使用临时 SVG 图案；失败页明确写出当前外层需要的颜色。

## 7. Motion and sound relationship

- 线轴按下 90–180ms；输入先给位移反馈，声音初始化不得阻塞。
- 同批精灵出洞基础间隔 190ms，并保留 0–30ms 的确定性差异。
- 单程行走约 560–1180ms；到达前针脚必须保持完整。
- 接触拆线约 260ms；空位释放、线束形成、纤维抖动在同一因果链内。
- 精灵返程、线束回收互不绑定。整批精灵回窝后至少再留 230ms，线束按个体额外错开 96ms，以 1160–1504ms 独立曲线钻回。
- 飞行线束初始可见长度约为精灵半径 3.2 倍，入洞阶段才逐渐收紧；速度升级不能通过缩短线束来伪造提速。
- 进入完成或失败状态时立即清掉未结束的动态任务，避免结算遮罩后仍堆积角色残影。
- `prefers-reduced-motion` 下减少摆动与曲线幅度，但保留输入、清除和状态变化。

## 8. Anti-patterns

- 不把高清图先压成统一低分辨率，再用大色块放大。
- 不把源图重新画成单层十字架；不可丢失针脚厚度、纤维、光泽和背景布纹。
- 不按素材页平均四等分；不把相邻图案边缘带入关卡。
- 不为补满方形画布拉伸闭合主体；不让左右边缘被圆形遮罩切掉。
- 不在拆线过程中填回“完成图”；拆掉的区域必须先成为真实空路。
- 不让精灵与线束同步回窝，也不把精灵变成无时间成本的飞行图标。
