## 动效、反馈与性能

`motion-polish-second-pass-0000..8200ms-390x844.png` 与 `motion-polish-narrow-second-pass-0000..8200ms-320x568.png` 在真实计时下覆盖放大后的精灵、190ms 排队出洞、地面步行、分批拆线、继续推进和加长线束异步回收。390×844 待拆数：

`1297 → 1297 → 1297 → 1296 → 1295 → 1293 → 1292 → 1290 → 1287 → 1286 → 1285 → 1282 → 1278 → 1275 → 1272 → 1267 → 1264`

结论：440ms 前没有提前拆线；约 660–880ms 出现首次真实结果；之后持续推进。两种视口均能看清个体出队间隔，精灵与线束使用不同回收时间线，3.2 倍半径的线身在入洞前保持可见。进入结算阶段时清除未结束的动态任务，避免角色残影堆积。

## 剩余真人测试

给 3–5 名未看过设计稿的中国用户直接打开第一关，不口述规则。第一次明显开路后询问：

1. 这一关最终要做什么？
2. 你接下来会反复看什么、点什么？
3. 怎样算进展，怎样会失败？

通过信号：至少 4 人能准确复述，并在第 3 关第一次自由选择时依据外层颜色而非随机尝试。否则优先调整外层提示与五槽表达，不继续增加新机制。
